# Access to the course material

This repository is a public (or shareable) **description layer**. The material itself stays on Google Drive.

## For readers without access

1. Read the course pages in this repository freely.
2. Clicking a 🔒 link opens Google Drive. If you are not signed in with an account that has been granted access, you will see *"You need access"*.
3. Click **Request access** and write a short note on who you are. The owner gets an email and decides.

## For the owner (maintenance rules)

- Keep the Drive folder `CoursesE26` restricted: General access = **Restricted**. Never switch it to *"Anyone with the link"* — every link in this repo would then become openly usable.
- Grant access per person (Viewer is enough for reading).
- Textbooks and course-supplied files are for personal study only; don't add them to this repository.
- Link by folder or file ID (`drive.google.com/drive/folders/<id>` or `drive.google.com/file/d/<id>/view`). IDs stay valid when files are renamed or moved inside Drive, but **not** if a file is deleted and re-uploaded — update the link then.
- New material: add it on Drive first, then add a row to the relevant course page.
