## About the links

Every link marked 🔒 points to Google Drive. The Drive folder is private to the owner, so:

- **Without access** you can read everything in this repository, but a Drive link will show Google's *"You need access"* page.
- **To get access**, click **Request access** on that page, or open an issue / contact the owner. Access is granted per person — no folder is shared publicly or via "anyone with the link".

See [ACCESS.md](ACCESS.md) for details.
